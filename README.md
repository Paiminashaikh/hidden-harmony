# 🎵 Hidden Harmony

Hidden Harmony is a music-inspired portfolio built with Django. It curates underrated Hindi songs grouped by mood and showcases full-stack development skills with clean UI and performance.

## 💡 Features

- Mood-wise horizontal scroll song tiles
- Django-admin powered CMS to add songs
- Custom responsive UI with animations
- Dark-themed professional design

## 🚀 Tech Stack

- Django (Backend)
- HTML, CSS, JS (Frontend)
- FontAwesome for icons
- Hosted locally (can be deployed)

## ⚙️ Setup Instructions

```bash
git clone https://github.com/yourusername/hiddenharmony.git
cd hiddenharmony
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
